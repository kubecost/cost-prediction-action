# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's private
vulnerability reporting: open this repository's
[Security tab](https://github.com/kubecost/cost-prediction-action/security)
and choose **Report a vulnerability**.

Do not report security vulnerabilities through public issues, discussions or
pull requests.

Please include the affected version or commit, steps to reproduce, and the
impact you expect.

## Supported versions

Only the latest release receives security fixes.
